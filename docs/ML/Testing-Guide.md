<span># Testing Guide</span>
<span></span>
<span>## What is Testing?</span>
<span></span>
<span>**Testing** ensures our code works correctly before it reaches production.</span>
<span></span>
<span>Think of it like quality control:</span>
<span>- Unit tests = Check individual parts</span>
<span>- Integration tests = Check parts work together</span>
<span>- End-to-end tests = Check whole system works</span>
<span></span>
<span>&gt; **Why this matters:** Tests catch bugs early, save debugging time, and give confidence to deploy.</span>
<span></span>
<span>---</span>
<span></span>
<span>## For Different Team Members</span>
<span></span>
<span>| Role | What Tests to Write |</span>
<span>|------|---------------------|</span>
<span>| **ML Engineer** | Unit tests for all functions |</span>
<span>| **QA/Testing** | Integration and E2E tests |</span>
<span>| **Backend Developer** | API contract tests |</span>
<span>| **Everyone** | Run tests before pushing code |</span>
